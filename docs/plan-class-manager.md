# 강남대학교 미니 방명록 기획서

> 프로젝트: guestbook-202104324
> 작성일: 2026-09-30
> 개발자: 장희현 (202104324)

## 1. 프로젝트 개요

강남대학교 실기시험을 위한 미니 방명록 웹앱이다. 누구나 이름, 메시지, 비밀번호를 입력해 글을 작성할 수 있으며, 작성자는 비밀번호를 확인한 뒤 자신의 글을 수정하거나 삭제할 수 있다.

## 2. 핵심 기능

| 기능 | 설명 |
|---|---|
| 글 작성 | 이름, 메시지, 비밀번호를 입력해 방명록 작성 |
| 글 조회 | 전체 글을 최신 작성순으로 표시 |
| 글 수정 | 작성자가 비밀번호를 입력하면 자신의 메시지 수정 |
| 글 삭제 | 작성자가 비밀번호를 입력하면 자신의 글 삭제 |
| 비밀번호 검증 | 잘못된 비밀번호 입력 시 작업을 거부하고 안내 메시지 표시 |

## 3. 사용자 흐름

1. 사용자가 이름, 메시지, 비밀번호를 입력한다.
2. 방명록 글을 등록한다.
3. 등록된 글은 최신 글부터 화면에 표시된다.
4. 작성자가 수정 또는 삭제를 선택한다.
5. 비밀번호가 일치하면 요청을 처리하고, 일치하지 않으면 오류 메시지를 표시한다.

## 4. 프로젝트 제약

- Next.js App Router
- TypeScript
- Neon Postgres
- Vercel 배포
- 별도의 Supabase 사용 없음
- 학생 식별 정보는 화면에 표시
