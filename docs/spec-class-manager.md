# Guestbook 기능 명세서

> 프로젝트: guestbook-202104324
> 작성일: 2026-09-30
> 개발자: 장희현 (202104324)

## 1. 화면

### 방명록 메인 화면

- 프로젝트 제목과 설명
- 개발자 이름 및 학번
- 방명록 작성 폼
- 등록된 방명록 목록
- 각 글의 수정/삭제 버튼

## 2. 글 작성

### 입력값

- 이름: 필수
- 메시지: 필수
- 비밀번호: 필수

### 처리

입력값을 검증한 후 데이터베이스에 저장한다. 저장된 글에는 비밀번호를 화면에 노출하지 않는다.

## 3. 글 조회

모든 방명록을 조회하고 작성일 기준 내림차순으로 표시한다.

## 4. 글 수정

수정 요청에는 글 ID, 비밀번호, 변경할 메시지가 포함된다.

- 글 ID와 비밀번호가 일치하면 메시지를 수정한다.
- 일치하지 않으면 수정하지 않고 오류 메시지를 반환한다.

## 5. 글 삭제

삭제 요청에는 글 ID와 비밀번호가 포함된다.

- 글 ID와 비밀번호가 일치하면 글을 삭제한다.
- 일치하지 않으면 삭제하지 않고 오류 메시지를 반환한다.

## 6. API

| Method | Endpoint | 기능 |
|---|---|---|
| GET | /api/guestbook | 방명록 조회 |
| POST | /api/guestbook | 방명록 작성 |
| PATCH | /api/guestbook | 방명록 수정 |
| DELETE | /api/guestbook | 방명록 삭제 |

## 7. 데이터

```text
guestbook
├── id
├── name
├── message
├── password
└── created_at
```

DB는 Neon Postgres를 사용한다.
